# P4: Try the example first

A theatre playbill puts the observed limit stop beside the unbuilt pacing idea, then lets visitors explore the real sample week's figures. Its invitation is to share their own mapped week so Jev can decide whether to build TokenMax.

## Six stages

1. Arrive in pain: explain the weekly limit and offer the sample without setup.
2. Understand: User 1 stops at the recorded limit; User 2 shows what Jev is designing and asks for a week.
3. Decide: see the example or contribute a week.
4. Run: explain local processing and sharing, then show the command at the end.
5. Read: explore real sample figures and open the built sample card.
6. Next: run and share the built map, or follow the unbuilt router work.
