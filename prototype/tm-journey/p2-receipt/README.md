# P2: The receipt

A limit notice is a torn ticket stub; the built map prints the itemised receipt for a real week. Opposite the stopped worker, a visibly unbuilt path shows what TokenMax is being designed to do, and the visitor is asked to share their own week to help decide whether to build it.

## Six stages

1. **Arrive in pain:** User 1 stops at the real sample limit time; User 2 shows the paced concept without a result.
2. **Understand:** Jev and the TokenMax router idea are explained as design, with the exact invitation to share a week.
3. **Decide:** The built map and shared board are described in plain words.
4. **Run:** Local processing and sharing are explained before the command, which ends the stage.
5. **Read:** The real builder's sample figures appear in an itemised receipt with the existing sample card link.
6. **Next step:** Run the built map and choose to share, or follow the router work while it is in design.
