Help me run the TokenMax usage mapper on my own computer. Do not upload anything and do not open any link it prints.
1. Ask me which logs to read: my Claude Code projects folder (often ~/.claude/projects), my Codex sessions folder (often ~/.codex/sessions), or none for either. Read no other folder.

4. In that folder run: bun map.ts --claude <folder or none> --codex <folder or none> --days <N> --out <a new folder name> --share
   For a date range, use --from YYYY-MM-DD --to YYYY-MM-DD instead of --days.
